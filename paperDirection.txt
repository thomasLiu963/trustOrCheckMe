Working narrative / scientific source of truth

==================================================
0. THE PAPER IN ONE PARAGRAPH
==================================================

D1 studies what happens when an LLM has already answered a question and must decide whether that frozen answer should receive an independent check.

The key intervention is unusually clean: keep the question and answer fixed, but change the confidence value shown back to the model.

Current exploratory evidence suggests that displayed confidence strongly changes HOW MANY answers the model sends for verification, while changing much less about WHICH answers it prioritizes. In simple terms, the score appears to act mainly like a threshold / coverage knob over a mostly stable ordering of which answers seem most worth checking.

Current leading hypothesis:

DISPLAYED CONFIDENCE STRONGLY MOVES VERIFICATION COVERAGE WHILE THE MODEL'S ITEM RANKING / DISCRIMINATION REMAINS LARGELY INVARIANT.

This replaces the older “hidden uncertainty gets crowded out” story.

==================================================
1. BASIC VOCABULARY
==================================================

SELF-VERIFICATION

The model first answers a question. That answer is frozen.

Then the model chooses:
- USE_UNVERIFIED: use the answer without an independent check.
- VERIFY_FIRST: send the answer to an independent verifier.

So “self-verification” here means the model deciding whether its own answer deserves an external check. It does NOT mean the model literally proves its own answer correct.

COVERAGE / VERIFICATION RATE

Coverage is simply the percentage of answers sent for verification.

If 70 of 100 answers are checked, coverage is 70%.

RANKING / PRIORITIZATION

Imagine the model has an implicit ordering:

1. answer A — most worth checking
2. answer B
3. answer C
4. answer D
5. answer E — least worth checking

A lower displayed confidence might make the model check A/B/C/D.

A higher displayed confidence might make it check only A/B.

The amount of checking changed, but the ordering did not.

RANKING INVARIANCE

Ranking invariance means displayed confidence changes the cutoff much more than it changes the ordering.

The paper's current question is therefore:

Does changing displayed confidence mostly move a threshold over one stable item ranking, or does it actually reshuffle which answers the model treats as risky?

==================================================
2. WHERE THE PROJECT STARTED
==================================================

Historical V2 used MMLU-Pro and four model families:
- GPT
- Claude
- Gemini
- Grok

Stage 1: answer the question.
Stage 2: report confidence that the frozen answer is correct.
Stage 3: choose USE_UNVERIFIED or VERIFY_FIRST.

Making confidence visible strongly changed verification behavior.

GPT was especially dramatic under explicit numerical costs.

At L=10:
- 0.89 displayed confidence -> essentially always VERIFY
- 0.91 -> essentially always USE

At L=20:
- 0.94 -> essentially always VERIFY
- 0.96 -> essentially always USE

Repeated generations showed this was not ordinary sampling noise.

So the displayed score itself is clearly a causal control input.

==================================================
3. WHAT WE NO LONGER BELIEVE
==================================================

The early interpretation was:

“Showing the score makes the model stop using richer hidden evidence.”

Later analyses weakened that.

GPT was overconfident. If GPT faithfully follows an overconfident probability, it will verify too little. That is a calibration / coverage problem, not proof that useful internal information was destroyed.

A second confidence report q2 also did not fully explain the natural VERIFY signal, but difficulty controls showed that much of the apparent extra information was simply:

hard questions are more likely to be wrong and more likely to be checked.

Therefore do NOT claim:
- hidden verification is privileged correctness knowledge;
- the model secretly knows when it is wrong;
- confidence suppresses a hidden truth signal;
- GPT loses internal evidence.

==================================================
4. THE EFFECT SURVIVES WITHOUT EXPLICIT ARITHMETIC
==================================================

Tasks 006/007 removed:
- numerical error cost;
- numerical verification cost;
- expected-value formulas;
- an exact threshold;
- “outweighs” / “justified” wording.

The score effect remained large.

GPT, moderate stakes:
- displayed 0.70 -> 59% VERIFY
- 0.90 -> 20%
- 0.99 -> 7%

GPT, stronger stakes:
- 0.70 -> 92%
- 0.90 -> 40%
- 0.99 -> 16%

Claude also responded monotonically.

Therefore the broad phenomenon is not simply “GPT did the arithmetic.”

Displayed confidence can strongly change verification coverage even without a computable decision rule.

==================================================
5. TASK 008: THE NEW CENTRAL RESULT
==================================================

Task 008 directly asked whether displayed confidence changes only coverage or also changes the item ranking.

Current decision:

INVARIANCE_SUPPORTED_EXPLORATORY

Current strength:

MODERATELY FAVORS ranking invariance.

Several pieces of evidence point the same way.

A. VERIFY sets were almost perfectly nested.

As displayed confidence increased, the model mostly removed items from the VERIFY set.

USE -> VERIFY reversals were essentially zero, except one small 2% GPT case.

That is what we expect if one threshold moves over a stable ranking.

B. A shared item propensity transferred across score conditions.

Task 008 learned which questions tended to be verification-worthy under some displayed scores and used that to predict decisions under another score.

This worked well, often with held-out-condition AUROCs around 0.7–0.94.

Lay interpretation:

If we learn which questions GPT or Claude distrusts at one displayed confidence, we can often predict which questions it will distrust at another confidence.

C. Richer score-specific models added little.

Models that allowed confidence to fundamentally reshape prioritization generally did not materially improve out-of-sample prediction.

D. Claude's old “sharpening” story is demoted.

The apparent widening of hard/easy percentage gaps can partly arise from ceiling/floor effects. Once analyzed on the proper latent scale and judged by out-of-sample usefulness, the evidence for a genuine Claude-specific ranking rewrite is weak.

==================================================
6. THE SIMPLEST WAY TO UNDERSTAND THE PAPER
==================================================

Imagine airport security has every passenger ranked from “most suspicious” to “least suspicious.”

Changing displayed confidence appears to change how far down that list the model goes.

Low displayed confidence:
check the top 60 passengers.

High displayed confidence:
check only the top 10.

But the top 10 are mostly still the same people who were at the top before.

That is the current hypothesis.

So:

CONFIDENCE = mainly controls HOW MUCH checking happens.

THE MODEL'S ITEM RANKING = mainly controls WHICH answers get checked first.

The surprising part is not that confidence changes the number of checks.

The surprising part is that a strong causal manipulation of confidence may move coverage dramatically while leaving the ordering almost intact.

==================================================
7. WHY RANKING MATTERS
==================================================

Suppose two systems both verify 20% of answers.

System A checks the 20% most error-prone answers.

System B checks 20% nearly at random.

Same verification cost. Very different usefulness.

So coverage alone is not enough.

A good oversight system needs:
- the right verification budget;
- a good ranking of which outputs deserve that budget.

If ranking invariance is true, showing a different confidence value is useful for tuning the amount of verification, but not for improving the ranking itself.

If the ranking is bad, changing the displayed score will mostly move up or down the same curve.

You need a better ranking signal.

==================================================
8. REINTERPRETING THE ORIGINAL WORKSHOP RESULT
==================================================

The original result looked like:

“Showing GPT its confidence makes it catch fewer errors.”

The cleaner explanation is now:

Showing confidence moved GPT to a lower-checking operating point, partly because GPT's confidence was overconfident.

If the ranking stayed mostly stable, GPT caught fewer errors mainly because it checked fewer answers.

So the current self-correction is:

OLD:
visible confidence harms verification quality.

CURRENT:
visible confidence strongly changes verification coverage; actual ranking degradation is much less established.

==================================================
9. WHAT IS ACTUALLY NOVEL
==================================================

Do NOT claim novelty for:
- confidence affecting abstention/escalation;
- risk-coverage curves;
- thresholded selective prediction;
- the distinction between coverage and ranking.

The potentially novel package is:

1. FIXED-ITEM COUNTERFACTUAL INTERVENTION
Same question, same frozen answer, different displayed confidence.

2. SELF-REFERENTIAL CONFIDENCE FEEDBACK
A model's confidence-style output is fed back as a control signal for whether its own already-produced answer gets checked.

3. RANKING-INVARIANCE TEST
Ask not only whether confidence changes verification, but whether it changes the ordering of which items receive scrutiny.

4. SYSTEMS CONSEQUENCE
If the displayed score only moves along a largely fixed ranking, then score manipulation tunes verification quantity without improving ranking quality.

==================================================
10. THE TWO POSSIBLE FINAL PAPERS
==================================================

WORLD 1 — RANKING INVARIANCE

Displayed confidence strongly changes coverage but leaves ranking/discrimination approximately stable.

Memory sentence:

“Counterfactual confidence feedback changes how much an LLM verifies far more than which answers it prioritizes.”

This is the current leading hypothesis.

WORLD 2 — RANKING RESHAPING

Displayed confidence changes both:
- how much checking happens;
- which outputs receive that checking.

Memory sentence:

“Counterfactual confidence feedback reshapes not only the amount of oversight but its allocation.”

If fresh data support World 2, pivot honestly. It may be even more interesting.

12. POSSIBLE FINAL CONTRIBUTIONS IF WORLD 1 IS CONFIRMED
==================================================

Maximum four main contributions:

1. COUNTERFACTUAL CAUSAL CONTROL
Changing only displayed confidence on the same frozen answer causally changes verification.

2. ARITHMETIC-INDEPENDENT SCORE CONTROL
The effect survives without explicit cost arithmetic.

3. RANKING INVARIANCE
Coverage changes dramatically while the ordering/discrimination of verification-worthy items remains approximately stable.

4. PRACTICAL CONSEQUENCE
Displayed confidence mostly moves the system along an existing risk-coverage relationship. Improving which outputs receive scrutiny requires improving the ranking signal, not merely changing the confidence value shown to the model.

==================================================
15. FALSIFICATION
==================================================

The prospective study must be capable of killing World 1.

Ranking invariance should be revised or rejected if fresh data show:
- substantial score-dependent reordering;
- frequent reversals beyond rerun noise;
- condition-specific ranking models materially outperform one shared ranking;
- discrimination changes meaningfully across non-saturated score conditions.

If that happens, the paper pivots to World 2 rather than hiding the result.
